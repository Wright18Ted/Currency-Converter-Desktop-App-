# Project Description 

Built a full-stack desktop app in Python (built and optimised for macOS) using Tkinter that serves as a currency converter. It connects user data with custom cross-rate logic and flat-file logging. 

The app uses a decoupled architecture with two main layers: an Ingestion & Processing Layer for the frontend calculator, and an Analytics & Storage Layer for the live dashboard both on the same page so that the user can see what they have previouly converted and plan their next conversion.
